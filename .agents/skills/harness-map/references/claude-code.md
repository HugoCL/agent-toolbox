# Claude Code

Claude Code reads skills from `.claude/skills/<name>/SKILL.md`. Two ways to get them there: `pnpm skills:install --dest claude --target <repo>` copies them, and inside this repo `pnpm skills:link` symlinks `.agents/skills` into `.claude/skills/` (gitignored). Claude Code documents per-skill directory symlinks. A symlink for the entire `.claude/skills/` directory is **UNCONFIRMED**. Read repo instructions in `CLAUDE.md` when present. pstack's Claude model rule is `~/.claude/rules/pstack-models.md`, and this repo's `$subagent-routing` takes precedence. [Skill discovery](https://code.claude.com/docs/en/skills.md), [pstack mapping](../../../docs/harness/claude-code.md)

- **Models and workers.** Select from the aliases in the live `Agent` schema. For example, `Agent({ description: "Review the patch", prompt, model: "opus", effort: "high" })`, with `effort` when the schema offers it. Per-call model wins over subagent frontmatter, `CLAUDE_CODE_SUBAGENT_MODEL`, and the parent model, in that order. Use `Explore` for read-only review where appropriate and brief it to avoid writes. A Claude alias cannot fill a GPT Sol seat.
- **Results and questions.** Collect a foreground result or the background completion notification. Use `AskUserQuestion({ questions: [...] })` if present. In print mode or when absent, put the question in the final reply.
- **PRs and issues.** Use the active forge tools or `gh`. Run the [vendored waiter](../../babysit-pr/scripts/pr-wait) with `Monitor` when offered, otherwise as one command.
- **pstack agents.** The pstack adapter names `pstack:poteto-agent` and `pstack:comment-sicko`. Those names exist only when the pstack plugin is installed, so with copied or linked skills alone they do not resolve. Translate each into a native call: read the definition in `.agents/agents/<name>.md` (the installer copies `.agents/agents/` only with `--dest agents`), put its body and the task in the `Agent` prompt, use `subagent_type: "general-purpose"`, and pass `model` and `effort` yourself from [subagent routing](../../subagent-routing/SKILL.md). The file's `model:` line holds a Cursor slug, so never pass it on.
